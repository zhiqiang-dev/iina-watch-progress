# IINA Watch Progress 0.1.3（开发预览版）

播放列表很长时，可一键返回正在播放的视频，并清楚查看最后位置、剩余时长与历史进度。持续播放时减少播放器属性读取、列表移动和隐藏界面的更新工作。

- **定位与跟随**：固定入口「定位当前」；切换视频时定位一次，使用滚轮、触控板或键盘浏览后暂停跟随。当前项被筛选隐藏时先提示，临时显示后可恢复原筛选。
- **浏览记忆**：按文件夹恢复选中、滚动锚点、搜索、筛选、排序、密度和跟随开关，最多 40 项。支持编号和多个关键词搜索。
- **列表信息**：位置/总时长、剩余时长、最近观看、播放状态，舒适/紧凑密度；详情展示分辨率、编码、实际观看、播放次数、路径和 Finder 入口。未知时长继续延迟获取。
- **双层进度**：浅色显示历史最远进度/完成标记，实色与圆点显示最后位置；当前视频拖动时预览，松手跳转，保持原播放/暂停状态。已完成后重播保持完成。
- **性能与保存**：缓存低频播放属性；顺序未变时不移动列表行；排序变化维持浏览锚点；合并隐藏视图更新。自动完成立即保存，普通位置继续按 5/15/30/60 秒设置批量保存。
- **兼容性修复**：处理 IINA 1.5.1 侧栏可见性返回空值，避免可见侧栏停止更新；播放器窗口复用时重新挂载侧栏。

安装文件：`iina-watch-progress-0.1.3.iinaplgz`。通过 IINA「设置 → 插件 → 安装本地插件…」安装，在方便中断播放时正常重启。设置页可能缓存旧版本号，重启后刷新。沿用原数据目录，schemaVersion 仍为 1，不需要清空记录。

验证：92 项自动测试、TypeScript 检查、构建和官方 CLI 打包通过；浏览器万项列表、深浅色与窄窗口验证通过；本机 IINA 1.5.1 验证侧栏实时进度、定位、拖动、暂停保存、自动下一项和关闭后重开。151 条身份完整保留，149 条课程记录完全一致，仅两条合成测试记录正常更新。

本版保留双快照 JSON，没有引入存储分片或追加日志。浏览偏好存于 WebView 本地存储，不包含在观看记录备份中；存储不可用时退为会话内记忆。元数据仅在文件实际加载后读取。隐藏更新优化受宿主可见性通知能力影响；完整多窗口压力、强制崩溃及实际 CPU/帧率/耗电仍待验收，性能数字的范围见 [性能说明](../performance.md)。
