# IINA Watch Progress 0.1.1（开发预览版）

首次具备对应 Git 源码提交的历史版本，提供本地视频观看记录、文件夹统计与继续观看。

- 按完整文件路径保存最后位置、历史最远位置、实际观看时长、播放次数与观看状态。
- 已完成状态保持，支持手动完成和重置；多播放器实例通过全局入口合并记录。
- 默认有变化时每 5 秒保存，暂停、切换和手动操作立即保存；双快照交替写入并校验恢复。
- 观看进度侧栏及独立窗口，支持状态筛选、搜索、排序、虚拟列表、播放/暂停和继续观看。
- 修复早期“正在连接观看记录…”持续显示和列表为空的跨上下文消息问题；在已有播放器窗口启用时重新附着。

发布核对：从源码提交 `5ff67ba0a85cb0119910d6d0ea0fec7d2a8ec81e` 导出后重新执行 TypeScript 检查、72 项测试和构建，全部通过；使用 IINA 官方 CLI 打包，归档内容与原始 0.1.1 安装包逐文件一致。

安装：下载 `iina-watch-progress-0.1.1.iinaplgz`，在 IINA「设置 → 插件 → 安装本地插件…」选择该文件。此版本用于历史留档，新用户建议使用 0.1.3。尚未完成完整多窗口压力、强制崩溃和跨系统兼容性验收。
