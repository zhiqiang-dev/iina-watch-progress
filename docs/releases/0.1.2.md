# IINA Watch Progress 0.1.2（开发预览版）

列表进度更新只传输变化记录，减少长列表反复排序与 DOM 创建；行左侧的圆形按钮现在可以直接播放、暂停当前视频。

- 当前视频播放时圆形按钮显示 `Ⅱ`，点击暂停；暂停时显示 `▶`，点击继续；点击其他视频按钮开始播放那个视频。列表获得焦点后空格可切换播放/暂停，双击和回车播放保留。
- Map 索引、增量统计/排序、可见行复用、每帧合并渲染、目录扫描缓存和暂停采样优化。
- 快照一次序列化，写后读回逐字验证；启动时完整校验及双快照恢复保留。
- 自动保存默认 5 秒，新增 15、30、60 秒选项。暂停、切换和手动操作立即保存；无变化不写盘。更长间隔意味着异常退出时可能丢失更长的最近进度。
- 小窗口中展开的设置区域可以独立滚动。

安装文件：`iina-watch-progress-0.1.2.iinaplgz`。通过 IINA「设置 → 插件 → 安装本地插件…」安装，在方便中断播放时正常重启 IINA。沿用原数据目录，schemaVersion 保持 1，无需清空已有记录。

验证：75 项自动测试、TypeScript 检查和构建通过，官方 CLI 打包；浏览器千项列表及播放控制验证通过，本机 IINA 1.5.1 验证当前视频圆形按钮播放、暂停和保存。性能数字来自合成记录、Node.js 和内存文件端口，不能视为实际 IINA CPU 或滚动帧率结果；详见 [性能说明](../performance.md)。仍为开发预览版，完整多窗口压力、异常退出及更多系统版本场景待验收。
