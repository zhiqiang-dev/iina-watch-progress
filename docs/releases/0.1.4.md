# IINA Watch Progress 0.1.4（开发预览版）

长列表搜索、滚动和持续播放时减少重复计算；新增快捷键、文件名编号定位、未完成视频导航和最近浏览文件夹入口。

- 搜索等待输入停顿 150 ms，中文组词期间不查询，Enter 立即应用；关键词/筛选复用已有排序，排序键变化时使缓存失效。
- 滚轮关闭跟随只执行一次；浏览状态未变时不重复写入 WebView 本地存储。
- 概览、继续观看、保存状态、导航和详情按依赖更新。只更新保存状态时不触发视频行绘制；当前视频在屏幕外且顺序不变时不重绘可见行。
- ⌘F 搜索、⌘L 定位当前、⌘J 按文件名开头编号定位。编号支持前导零和全角数字，重复编号提示用关键词搜索；目标被筛选隐藏时可临时显示并恢复原筛选。
- ↑ / ↓ 工具栏按钮选择当前筛选、排序中的上一/下一个未完成视频，不循环；回车或播放按钮开始播放。
- 文件夹下拉框提供最多 40 个最近浏览目录；切换保持当前播放，离线目录保留原列表并提示。

安装文件：`iina-watch-progress-0.1.4.iinaplgz`，附带同名 `.sha256` 校验文件。通过 IINA「设置 → 插件 → 安装本地插件…」安装后正常重启 IINA。记录仍为 schemaVersion 1，沿用原目录和保存间隔，无需清空记录。未自动安装到本机正在运行的 IINA。

验证：109 项自动测试、TypeScript 检查和构建通过；DOM 测试覆盖输入法、快捷键、筛选恢复、未完成导航、屏幕外更新、保存状态局部刷新、完成状态和拖动取消。合成一万条记录 100 次查询耗时中位数约 194 → 87 ms，完整排序含初次加载由 100 次降至 1 次。方法及原始数据见 [性能说明](../performance.md)。jsdom 仅用于开发测试，不进入发布包。

本次界面控制工具连续超时，未完成 0.1.4 真实 IINA/浏览器外观与交互、新截图及 CPU/帧率/耗电测量。DOM 测试不计算真实布局、绘制或宿主快捷键拦截。仍为开发预览版；双快照全量 JSON 存储未改为分片或追加日志，未增加备份导入导出界面。
