## 0.1.1 本机故障修正

2026-11-25 在本机 IINA 1.5.1 复现：插件已经启用，双快照含 149 条记录，窗口却始终显示“正在连接观看记录…”和空列表。记录仍在，故障发生在全局实例到播放器窗口的消息回传。诊断过程中曾触发 JavaScriptCore 跨上下文调用/回收崩溃，崩溃栈涉及 IINA 的 `JavascriptMessageHub.callListener` 与 `JavascriptAPIGlobalController.postMessage`。

修正措施：全局消息显式 JSON 序列化、下一轮事件循环再发送、合并同一窗口的待发快照、在 JavaScript 全局根中保留回调与端点。补充在已有播放器窗口启用插件时的初始化，避免依赖不会重放的 window-loaded/file-loaded 事件。最终安装的脚本不含临时诊断代码。

自动验证：`pnpm check` 通过，56/56 测试；新增禁止同步跨上下文回复的集成桩，覆盖异步消息、快照冻结、合并、关闭窗口、热加载及无效消息。官方 CLI 成功生成 0.1.1 安装包。

实机验证使用 `/private/tmp/iina-watch-progress-verification/` 中两个无声合成视频，已确认：真实独立窗口显示记录、已完成状态和上次位置跨重启保留、播放位置自动更新、暂停保存、手动完成与重置同步、重置后重新播放继续累计。更新后的初次比对确认原有 149 条记录完整保留，业务字段与诊断前备份一致；另外新增了 2 条合成视频测试记录。之后正常播放课程时，记录会继续更新，不应拿旧备份覆盖这些新进度。
