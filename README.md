# IINA Watch Progress

为 IINA 增加本地视频观看记录和文件夹进度。使用 TypeScript、官方插件 API、原生 HTML/CSS、esbuild 和 JSON，无运行时第三方依赖，不修改视频，不访问网络。

当前版本为 **0.1.3 开发预览版**，以 IINA **1.5.1** 为验证目标。自动测试通过不代表所有真实播放器场景已经验收。

0.1.3 增加一键定位、播放跟随、按文件夹恢复浏览位置、多关键词搜索、列表密度和视频详情。双层进度条区分最后位置与历史最远位置，当前视频可拖动预览、松手跳转。进一步缓存播放属性、减少无效排序移动，并处理隐藏界面的消息。见 [性能说明](docs/performance.md) 和 [0.1.3 发布说明](docs/releases/0.1.3.md)。自动保存仍默认 5 秒，可选 15、30、60 秒；暂停、切换和完成等重要操作立即保存。

0.1.1 修复了 0.1.0 中“正在连接观看记录…”持续显示、列表为空的跨实例消息问题，并支持在已有窗口启用插件后重新附着。已在本机 IINA 验证记录显示、暂停保存、跨重启恢复和手动操作；完整验收进度见 [验收记录](docs/acceptance.md)。升级沿用原有数据目录，无需清空记录。

**第一次使用：**请阅读 [带截图的中文使用指南](docs/使用指南.md)，包含本地安装、继续观看、搜索筛选、手动标记、设置、备份恢复和常见问题。普通使用直接安装 `release/` 中的 `.iinaplgz`，无需安装开发工具。

## 已实现

- 同步 IINA 当前播放列表，补充当前文件夹中的直接子视频，按完整路径区分同名文件。
- 记录最后位置、最远位置、实际观看时间、播放次数及观看状态。
- 实际播放累计 5 秒进入观看中；默认播放位置达到 95% 或收到确认的 EOF 时完成。
- 已完成状态永久保留，直到用户手动重置；支持手动完成、重置。
- 多播放器窗口通过全局实例统一修改数据；有变化时默认每 5 秒保存，可选 15/30/60 秒；暂停、切换、结束和关闭窗口时保存。
- 双快照交替写入、版本号、校验与写后读取验证；一份损坏时恢复另一份，两份均损坏或遇到更新版本时停止写入。
- 文件夹完成数、观看中数量、完成率；搜索、状态筛选、自然文件名/进度/最近观看排序。
- 点击行左侧圆形按钮播放/暂停，列表获得焦点后空格切换；双击或回车播放；一键继续当前文件夹最近观看的未完成视频。
- 一键定位当前视频；切换视频时跟随定位，使用滚轮、触控板或键盘浏览后暂停跟随；被筛选隐藏时提供临时显示和恢复筛选。
- 按文件夹记住选中、滚动锚点、搜索、筛选、排序和密度，最多保留 40 个文件夹的界面偏好。
- 行内显示位置/总时长、剩余时长和最近观看；舒适/紧凑密度；详情显示分辨率、编码、实际观看时长、播放次数和路径。
- 双层进度条展示历史最远与最后位置；当前视频支持拖动跳转，暂停状态保持。
- 跟随系统浅色/深色外观；独立窗口；80%～100% 完成阈值。
- 虚拟列表只创建视口附近的行，以支持较长的播放列表。

## 开发与构建

需要 Node.js 22、pnpm 10、macOS 和已开启插件系统的 IINA。

```sh
pnpm install
pnpm check
pnpm run package
```

产物位于 `release/iina-watch-progress-0.1.3.iinaplgz`。打包使用 IINA 自带的官方 CLI；如果 IINA 安装在其他位置：

```sh
IINA_PLUGIN_CLI=/path/to/IINA.app/Contents/MacOS/iina-plugin pnpm run package
```

通过 IINA 设置中的插件安装入口选择 `.iinaplgz`，启用后重新打开播放器窗口。然后在「插件」菜单中选择「显示观看进度」或「独立观看列表」。

开发时也可链接构建目录，再重启 IINA：

```sh
pnpm build
/Applications/IINA.app/Contents/MacOS/iina-plugin link ./dist
pnpm dev
```

`pnpm dev` 监视 TypeScript、HTML、CSS 和清单变更。UI 静态资源变化可重新加载 WebView；播放器脚本变化需重启 IINA。取消开发链接：

```sh
/Applications/IINA.app/Contents/MacOS/iina-plugin unlink ./dist
```

## 交互预览

```sh
pnpm build
pnpm preview
```

打开 <http://127.0.0.1:4173>。预览使用独立的示例数据，仅模拟界面操作，不连接 IINA，也不写入真实观看记录。`/?count=1000` 可检查长列表，`/?empty` 可检查空状态，`/?appearance=dark` 或 `light` 可预览主题。

性能复现：`pnpm benchmark` 测量合成记录的 JavaScript 消息体积、快照处理和列表计算；`/?count=1000&benchmark=1&live=1` 可查看持续更新时的虚拟列表指标。结果不代表 IINA 的实际 CPU、帧率或磁盘性能，方法与限制见 [性能说明](docs/performance.md)。

## 使用规则

在 IINA 中打开本地视频或文件夹，再显示插件侧边栏。文件夹统计包含该目录下支持的视频文件，包括没有进入 IINA 播放列表的视频，不包含子目录。目录无法读取时，界面会明确提示仅统计播放列表中的文件。文件夹选项来自当前播放列表和正在播放的视频；切换播放列表不会删除历史记录。

普通打开和双击播放由 IINA 原生断点续播处理，插件不自动 seek。点击「继续观看」会在目标文件开始播放后，明确跳转到插件保存的最后位置。全部未观看时，从自然排序的第一个视频开始；全部完成时按钮禁用。

重置正在播放的视频会让所有播放该文件的窗口暂停并回到开头，防止下一次采样立即恢复旧的完成状态。再次播放后重新累计。修改完成阈值只影响后续判断，不撤销已完成记录。

百分比使用**历史最远播放位置**，已完成的显示进度为 100%；浅色条表示这个历史进度/完成标记，实色和圆点表示最后位置。拖动只对当前视频生效，不自动打开其他视频；拖动期间预览，松手后跳转，并保持原暂停状态。直接拖到完成阈值也会完成，这不是实际观看覆盖率。实际观看时长按墙上时间估计，排除暂停、明显跳转、缓冲和长时间休眠；2 倍速播放一秒仅累计一秒。同一文件同时在多个窗口播放时，观看时间会累计各窗口的播放时间，最后位置以最后收到的采样为准。

「定位当前」只定位/选择，不开始播放或改变位置。筛选隐藏当前项时，点击「显示当前视频」才临时放宽筛选，之后可恢复。恢复已有文件夹时优先保留上次浏览位置，不强制滚回播放项；可随时点击定位。界面偏好以 600 ms 去抖写入 WebView 本地存储，存储不可用时退为当前会话记忆，不写入观看记录快照。

## 数据与恢复

数据写入官方 `@data/` 私有目录，标识符为 `io.iina.watch-progress`。可通过侧边栏「设置与数据 → 在 Finder 中显示记录」定位。当前 IINA 的通常位置是：

```text
~/Library/Application Support/com.colliderli.iina/plugins/.data/io.iina.watch-progress/
├── records.json
└── records.backup.json
```

两个文件是**交替使用的有效快照**，恢复时选取校验通过且 `revision` 最高的一份，不能仅凭文件名认定新旧。设置与视频记录在同一快照中保存，防止状态不同步。FNV 校验用于发现意外损坏，不用于安全认证。

运行中请勿手工修改快照。备份时先退出 IINA，再复制整个数据目录。两份均无法读取时插件保留原文件、显示错误并停止写入；先备份目录，再排查磁盘权限、空间或损坏。未来格式的记录也会进入只读保护，需升级插件，不能降级覆盖。

正常保存间隔默认 5 秒，可在设置中改为 15、30、60 秒；更新内存/界面不等于写盘，暂停且数据未变化时不重复写入。异常强制退出可能丢失最近约一个保存周期的更新；若最新一次写入损坏，备用快照可能再落后一个周期。磁盘持续写入失败时，界面会显示未保存并自动重试，不承诺恢复尚未落盘的数据。

## 范围与限制

- V1 按词法标准化完整路径识别，保留大小写及 Unicode；不解析符号链接、不识别重命名和移动。
- 只处理已列出的本地视频扩展名；不记录网络流、音频、DVD/蓝光虚拟路径，不递归扫描。
- 尚未播放的视频时长未知，显示「—」；不为统计批量探测大视频。
- 分辨率/编码仅在文件实际加载后获取，当前界面最多缓存 100 个视频的参数，不批量扫描或永久保存媒体参数。
- 100% 阈值依赖实际到达时长或可确认的 `eof-reached`。IINA 未向插件透传 `end-file` 的 reason；插件不会将停止、切换或错误直接视为看完。
- 多窗口协调覆盖同一个 IINA 进程内的播放器窗口，不支持同时运行多个独立 IINA 进程写入同一数据目录。
- 本版未实现课程库、文件迁移、观看区间覆盖率、备份导入/导出 UI、自动跳过完成项或原生历史迁移。

## 架构与验证

`src/main.ts` 负责播放器事件与 WebView，`src/global.ts` 是唯一写入入口。纯业务模块位于 `src/core/`；存储、快照格式和验证位于 `src/storage/`。UI 使用消息桥接，不直接访问播放器或文件系统。浏览器预览的桥接仅进入 `dist/preview.js`，发布包会排除该文件。

`pnpm test` 覆盖状态机、倍速/跳转/暂停、媒体身份、文件夹聚合、快照中断/损坏/未来版本、多窗口合并与重置，以及编译后 main/global 在模拟 IINA API 下的事件集成。真实播放器验收记录见 [docs/acceptance.md](docs/acceptance.md)。
